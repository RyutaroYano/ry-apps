# ry-apps

個人用のウェブアプリ置き場。ビルドステップなしの静的サイトで、[GitHub Pages](https://pages.github.com/) でホスティングし、独自ドメイン `apps.ryutaroyano.jp` を設定している。

## 構成

```
ry-apps/
├── CNAME                         # 独自ドメイン（apps.ryutaroyano.jp）
└── skills/gamification.html      # ゲーミフィケーション自己報酬アプリ
```

このリポジトリは公開。合言葉などの秘密情報は置かない。

## 🎲 ゲーミフィケーション自己報酬アプリ (`skills/gamification.html`)

普段の行動を「サイコロで報酬を引く」ゲームに変える、個人用の自己管理アプリ。

やるべきことをやったら点数が貯まり、貯めた点数でサイコロを振ると、湯船・外食・スマホタイムなどの報酬が確率で当たる。当たり前にできるはずのことを、あえて「引かないと手に入らないもの」にすることで、日々の行動にちょっとしたドキドキと、当たり前への感謝を取り戻すことを狙っている。

タナカミノルさんの「ドーパミントリガー」というセミナーで語られていたゲーミフィケーション理論——報酬の大きさではなく、結果の不確実性と、自分の行動がその確率に影響を与えるという実感こそがモチベーションを生む、という考え方——を土台にしている。

### 特徴

- **罰則は一切ない。** やらなかったからといって減点されることはなく、報酬を取りにいく前向きな仕組みだけで作られている。
- **サイコロの目は線対称。** 2つのサイコロには本来「どちらが1個目か」という区別がないので、目の組み合わせがどちらの順番でも同じ報酬になるよう設計している。手で実際にサイコロを振って結果を入力することもできる。
- **PC・スマホどちらからも同じデータにアクセス可能。** Google Driveと連携して、記録がどの端末からでも同期される。
- **オフラインでも使える。** ネットが繋がっていない場所でボタンを押しても記録は端末に残り、繋がった瞬間に自動で同期される。
- **日々の記録を自動でスプレッドシートに。** 何をどれだけやったかが、カテゴリ（土台・健康・人間関係・スキル・経済）ごとに自動で集計されていく。

ブラウザで動く1枚のHTMLファイルで、開くと合言葉の入力を求められる（個人利用のため、非公開の合言葉を知っている人だけが自分の記録にアクセスできる仕組み）。技術構成は素のHTML/CSS/JavaScript＋Google Apps Script（データ保存）。
